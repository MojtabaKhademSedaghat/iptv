# IPTV — Iran only

پلی‌لیست کانال‌های ایرانی از [iptv-org/iptv](https://github.com/iptv-org/iptv)، آماده روی این فورک.

## لینک پلی‌لیست

```
https://mojtabakhademsedaghat.github.io/iptv/index.m3u
```

نسخهٔ جایگزین:

```
https://mojtabakhademsedaghat.github.io/iptv/ir.m3u
```

این لینک را در VLC، IPTV Smarters، TiviMate یا هر پلیر سازگار با M3U باز کنید.

## همگام‌سازی

Workflowی `sync-iran` هر ۱۲ ساعت پلی‌لیست ایران را از منبع اصلی می‌گیرد و داخل `docs/` به‌روز می‌کند.

دستی هم می‌توانید از تب **Actions** → **sync-iran** → **Run workflow** اجرا کنید.

## منبع

کانال‌ها و استریم‌ها متعلق به این ریپو نیستند؛ فقط لینک‌های عمومی منتشرشده توسط iptv-org همگام می‌شوند.
